# Описание unit-тестов

Документ описывает тест-кейсы для проекта `EmailMassSender`. Каждый кейс имеет
идентификатор, который совпадает с префиксом имени тестового метода
(например, `R01` → `R01_Disabled_ReturnsFalse`).

Тесты разбиты на две группы:

- **R** — `EmailMassSendingHostRecycler` (повторный запуск обработки задач);
- **S** — `EmailMassSendingService` (подготовка задач и отправка писем).

Тесты сервиса работают с файловой системой во временной директории и не
используют реальный SMTP-сервер. Отправка писем проверяется либо с отключённым
SMTP (`SmtpClient.Enable = false`), либо через локальный фейковый SMTP-сервер
(см. [README.md](README.md)).

---

## R. EmailMassSendingHostRecycler

| ID  | Сценарий | Исходные данные | Ожидаемый результат |
|-----|----------|-----------------|---------------------|
| R01 | Повтор выключен | `Enable = false` | `TryRecycleAsync` возвращает `false` |
| R02 | Нет конфигурации | конфигурация `null` | Повтор выключен по умолчанию, `TryRecycleAsync` возвращает `false` |
| R03 | Повтор включён | `Enable = true`, `Delay = 0`, окно 1 час | `TryRecycleAsync` возвращает `true` |
| R04 | Ограничение количества повторов | `CountOfRecycles = 3` | Первые два вызова возвращают `true`, третий — `false` (первый запуск тоже считается) |
| R05 | Окно повторов истекло | `RecyclingWindow = 0` | После истечения окна `TryRecycleAsync` возвращает `false` |
| R06 | Запрошена отмена | токен уже отменён | `TryRecycleAsync` возвращает `false` без ожидания |
| R07 | Задержка перед повтором | `Delay = 200 мс` | `TryRecycleAsync` ждёт не меньше заданной задержки |
| R08 | Значения по умолчанию | пустая конфигурация (все поля `null`) | `Enable = false`, `CountOfRecycles = int.MaxValue`, `RecyclingWindow = 1 ч`, `Delay = 10 с` |

## S. EmailMassSendingService

### Конструктор

| ID  | Сценарий | Исходные данные | Ожидаемый результат |
|-----|----------|-----------------|---------------------|
| S01 | Конфигурация не передана | `configuration = null` | `ArgumentNullException` |
| S02 | Некорректное число потоков | `Threads = 0` | `Threads` становится `1` |
| S03 | Нет стратегии повторной отправки | `RollUpStrategy = null` | Создаётся стратегия по умолчанию: `Enable = false`, `Delay = 0`, `MaxCount = 1` |

### Подготовка задач

| ID  | Сценарий | Исходные данные | Ожидаемый результат |
|-----|----------|-----------------|---------------------|
| S04 | Нет групп | `Groups = null` | `SendAsync` завершается без ошибок, файлы задач не создаются |
| S05 | Создание файла задачи | одна группа, 2 получателя | Создаётся файл `<группа>_<MD5 текста>.task`, в нём 2 элемента |
| S06 | Дубликаты получателей | получатели `a`, `a`, `b` | В задаче 2 элемента (дубликаты удалены) |
| S07 | Фильтр групп через `DefaultGroups` | группы `g1`, `g2`, `g3`; `DefaultGroups = "G1;g3"` | Задачи созданы только для `g1` и `g3` (регистр не важен) |
| S08 | Все группы | `DefaultGroups = "*"` или `null` | Задачи созданы для всех групп |
| S09 | Нет получателей | `Receivers = null` | Файл задачи не создаётся, исключения нет |
| S10 | Нет файла с текстом | `PlainTextFileName` указывает на несуществующий файл | Группа пропускается, остальные группы обрабатываются |
| S11 | Директория задач отсутствует | `TasksPath` не существует | Директория создаётся |
| S12 | Удаление устаревших задач | `DeleteObsoleteTasks = true`, в директории старый `.task` | Старый файл удалён, свежий сохранён |
| S13 | Устаревшие задачи не удаляются | `DeleteObsoleteTasks = false` | Старый файл сохранён |
| S14 | Нет SMTP-настроек | `SmtpClient = null`, есть задачи | `InvalidOperationException`; файлы задач закрыты до выброса исключения |

### Обработка задач (SMTP выключен)

| ID  | Сценарий | Исходные данные | Ожидаемый результат |
|-----|----------|-----------------|---------------------|
| S15 | Обработка при выключенном SMTP | `SmtpClient.Enable = false` | У всех элементов заполнен `Attempt`, `Failed = false`, `Failure = "Not sent (disabled)"` |
| S16 | Повторное использование задачи | существует файл задачи, элемент уже отправлен | Элемент не обрабатывается повторно (`Attempt` не меняется) |
| S17 | Сброс задач | `ResetTasks = true`, элемент уже отправлен | Задача пересоздаётся, элемент обрабатывается снова |
| S18 | Счётчик попыток | `RollUpStrategy.Enable = true`, `MaxCount = 5` | После обработки `AttemptsLeft = 4` |
| S19 | Попытки исчерпаны | в задаче элемент с `AttemptsLeft = 0` и `Failed = true` | Элемент не обрабатывается |
| S20 | Истёк срок актуальности | в задаче элемент с `Lifetime` в прошлом | Элемент не обрабатывается |
| S21 | Ожидание повтора | в задаче элемент с `WaitFor` в будущем | Элемент не обрабатывается в этом проходе |
| S22 | Несколько потоков | `Threads = 3`, 10 получателей | Все 10 элементов обработаны |

### Отправка через SMTP (фейковый сервер)

| ID  | Сценарий | Исходные данные | Ожидаемый результат |
|-----|----------|-----------------|---------------------|
| S23 | Успешная отправка | фейковый SMTP-сервер принимает письма | Сервер получил письма для всех получателей; элементы `Failed = false`, `Failure = null` |
| S24 | Содержимое письма | тема, текст, отправитель | Сервер получил `MAIL FROM` с адресом отправителя и `RCPT TO` с адресом получателя |
| S25 | Ошибка отправки | сервер сразу закрывает соединение | Элемент `Failed = true`, `Failure` заполнен, `WaitFor` = время попытки + `RollUpStrategy.Delay` |
| S26 | Повторная отправка после ошибки (регрессия) | сервер всегда отклоняет; `RollUpStrategy`: `MaxCount = 3`, `Delay = 300 мс`; `HostRecycle` включён | Выполнены все 3 попытки, `AttemptsLeft = 0`. До исправления элемент, ожидающий повтора, считался успешно обработанным, и повтора не было |
| S27 | Отмена по таймауту | токен отменяется во время работы | `SendAsync` завершается без зависания, файлы задач закрыты |
